💾 8-bit Register

0
Bit 7 = Presence
Bit 6 = Late
Bit 5 = Leave
Bit 4 = Reserved
Bit 3-1 = Zone
Bit 0 = Verification Method (แสดงตัวอย่างตามแนวคิด)

👨‍🎓 รายชื่อนักเรียน

นักเรียนโซนวิธีเวลาสถานะ

⚙️ วิธีใช้งาน

1. กรอกชื่อ โซน วิธีตรวจสอบ และสถานะ
2. กด “เพิ่มและบันทึก”
3. คลิกแถวชื่อนักเรียนเพื่อดู 8-bit Register
4. ทดลองปุ่ม “เริ่มสแกนใบหน้า” เพื่อจำลองการเช็กชื่อ
5. ข้อมูลทั้งหมดเก็บไว้ในหน้านี้ชั่วคราว
